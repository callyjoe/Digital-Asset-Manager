Digital Asset Manager (DAM) Prototype


Overview

This project is a front-end prototype for a Digital Asset Management system. It is designed to provide a seamless user interface for organizing, filtering, and uploading visual assets (such as apparel mockups, typography files, and web elements).

The core objective of this build was to demonstrate a strong command of responsive web design and array-like data filtering using Vanilla JavaScript, ensuring a smooth user experience without relying on heavy external libraries.
Key Features

    Dynamic Category Filtering: Users can instantly sort assets by tags (Apparel, Branding, Web Elements) using a custom JavaScript filtering function that triggers smooth CSS transitions.

    Simulated Upload Engine: Features an input system that captures user tags, dynamically generates new HTML asset cards, and prepends them to the DOM in real-time.

    Responsive Grid Architecture: Utilizes modern CSS Grid to create a responsive, masonry-style gallery that fluidly adapts to any screen size from mobile to desktop.

Tech Stack

    HTML5: Semantic structure and accessibility.

    CSS3: CSS Grid, Flexbox, Custom Properties (Variables), and CSS Animations.

    Vanilla JavaScript (ES6+): DOM manipulation, event listeners, and data-attribute filtering.
